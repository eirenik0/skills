# Assets Directory

This directory can contain sample files and resources for the z.ai MCP skill.

## Suggested Contents

- **Sample Images**: Example images for testing image analysis
- **Example URLs**: List of test URLs for web fetching
- **Sample Queries**: Example search queries
- **Configuration Templates**: Sample .mcp.json configurations

## Usage

Assets in this directory can be referenced in examples and testing.

### Example Structure

```
assets/
  ├── images/
  │   ├── test-screenshot.png
  │   ├── sample-document.jpg
  │   └── example-diagram.png
  ├── urls.txt
  └── example-queries.txt
```

## Notes

- Keep assets small and relevant
- Don't commit sensitive or proprietary content
- Use public domain or licensed materials
- Document source and license for each asset
